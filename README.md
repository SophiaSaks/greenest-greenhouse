# Greenest Hotel

#### This is a console application I made for a course in object oriented programming to learn concepts such as polymorfism, interfaces, enums, inheritance, etc.

[![Architecture diagram of sophiasaks/greenest-greenhouse](https://gitdiagram.com/sophiasaks/greenest-greenhouse/diagram.png)](https://gitdiagram.com/sophiasaks/greenest-greenhouse?utm_source=readme&utm_medium=picture)

## Features
-  Enter the name of a plant that stays in the hotel
- Displaying which liquid and amount it needs to drink per day
- Handles errors if a plant is not found


## Technologies
- Java
- OOP

## How to run: 
Open the project in your preferred IDE and run the application from the terminal
